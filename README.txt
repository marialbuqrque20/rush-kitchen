# Rush Kitchen Mobile Multiplayer

Versão adaptada para celular.

O que tem:
- Multiplayer online por sala
- Até 3 jogadores
- Controles touch na tela
- Botão de ação
- Layout responsivo para celular
- Avatar Chef Ruiva, Chef, Pirata e Palhaço
- Cozinhar, montar e entregar pratos
- Tempo, pontuação e estrelas

Como rodar no computador:
1. Instale o Node.js.
2. Abra o terminal dentro da pasta.
3. Rode:
   npm install
   npm start
4. Abra:
   http://localhost:3000

Para jogar cada um em uma casa:
- Hospede em um serviço que aceite Node.js + WebSocket, como Render, Railway ou Fly.io.
- Envie o link para a outra pessoa.
- Uma pessoa cria a sala e a outra entra pelo código.

No celular:
- Abra o link pelo navegador.
- Use o direcional na tela e o botão AÇÃO.
- Melhor jogar com o celular na horizontal.
